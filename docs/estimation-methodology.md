# Estimation methodology

Private exits model `equity value = enterprise value − debt + cash`, then `gross proceeds = equity value × ownership × cash consideration`. Net liquidity subtracts modeled tax, fees, escrow, rollover equity, and documented obligations.

Public sales calculate observed gross proceeds as shares sold × transaction price. Net proceeds remain ranges.

The deterministic Monte Carlo engine supports explicit distributions, seeded sampling, configurable counts, percentile outputs, and sensitivity analysis. Remaining liquidity adds new net liquidity, subtracts known deployment and a separately disclosed unobserved-deployment assumption, and never falls below zero.
